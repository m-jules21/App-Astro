# Astro — jeu iPhone

Petit jeu d'arcade natif écrit en SwiftUI. Fais glisser ton doigt pour déplacer le vaisseau et éviter les météorites.

## Ouvrir sur un Mac

1. Copie le dossier `Astro` sur le Mac.
2. Ouvre `Astro.xcodeproj` avec Xcode.
3. Branche l'iPhone, déverrouille-le et accepte « Faire confiance » si demandé.
4. Dans Xcode, choisis l'iPhone comme destination. Dans **Signing & Capabilities**, coche **Automatically manage signing**, puis sélectionne ton compte Apple personnel dans **Team**.
5. Appuie sur **Run ▶**. Au premier lancement, suis les instructions de l'iPhone pour autoriser le développeur.

L'installation avec un compte Apple gratuit est destinée aux essais personnels et sa signature doit être renouvelée périodiquement (souvent tous les 7 jours). GitHub Education ne fournit pas à lui seul un Mac ni un compte développeur Apple.
